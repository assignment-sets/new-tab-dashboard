    Install in under a minute.

    Not on the Chrome Web Store yet. Load the open-source folder directly in Chrome.

    1. 1

      Download & unzip

      Save the archive and extract it to a permanent folder.

      new-tab-dashboard-main.zip Download .zip
    2. 1

      Clone the repository

      Clone locally so updates stay one pull away.

      $git clone https://github.com/assignment-sets/new-tab-dashboard.git
    3. 2

      Open Chrome extensions

      Paste into your address bar and turn on Developer mode.

      chrome://extensions
    4. 3

      Load the extension folder

      Click Load unpacked and pick the extension subfolder.

      new-tab-dashboard / extension/ Select folder
    5. 4

      Keep it & pin

      Open a new tab, choose Keep it, and pin New Tab-Dashboard.

      New tab prompt→Keep it Pin icon

    Also works in Brave, Edge, Arc, and Vivaldi via their extensions page.

    Details & privacy.

    Permission Scope Purpose
    storage Required Saves tasks, reminders, pinned sites, notes, and weather city in local extension storage.
    alarms Required Schedules the next pending reminder so timers fire even when no New Tab is open.
    offscreen Required Plays the local chime audio file when a timed reminder becomes due.
    notifications Optional Requested only if you opt into desktop alerts; missed reminders otherwise stay in the inbox popover.
    open-meteo.com Optional host Queried only when searching for a city or refreshing current weather forecasts.

    All data stays in your Chrome profile. Clearing cache or history keeps it; uninstalling removes it.

    How do I update without losing my data?

    Download the latest archive or run git pull, replace the files in your unpacked directory, and click Reload on chrome://extensions. All tasks, notes, pins, and weather settings stay intact in Chrome profile storage.

    Why isn't it on the Chrome Web Store?

    Distributing unpacked source keeps the extension simple to inspect, modify, and run locally without store packaging or external tracking.

    What if another extension controls my New Tab page?

    Chrome allows one active New Tab override per profile. Disable the conflicting extension on chrome://extensions, or select Keep it when Chrome prompts on your first new tab.

    How do I run tests locally?

    Install Node.js 20 or later, open the repository root in a terminal, and run npm test. The project uses native ES modules with zero build step and zero runtime dependencies.
